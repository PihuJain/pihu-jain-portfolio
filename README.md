# Pihu Jain portfolio

A static, responsive portfolio built with HTML, CSS, and a small amount of JavaScript. It includes Home, Projects and five project pages, Sticker wall, About, Resume, Contact, and a 404 page. No package install or build step is needed.

## Preview locally

Open `index.html` in a browser or serve this folder with a basic static file server. This site has no package install or build step; upload the folder containing `index.html` to a static host.

## Personalize later

- Add your resume PDF to the Resume page when it is ready.
- Add your personal contribution, screenshots, and any updated outcomes to each project page.
- Add or change projects as your GitHub portfolio grows.

The portfolio uses the supplied illustrated avatar, your contact and profile links, a FAANG-inspired text sticker wall, and VT323 for pixel-style labels.
